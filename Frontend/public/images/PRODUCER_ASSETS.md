# Imagens ilustrativas dos produtores

Criadas em 8 de novembro de 2026 com a ferramenta integrada `image_gen.imagegen` (skill Imagegen, modo built-in). Não foi utilizado o CLI nem uma API externa pelo projeto.

Estas imagens são cenários genéricos gerados por IA para ilustrar a atividade de carcinicultura. **Não representam as instalações de nenhum produtor cadastrado**, nem devem ser apresentadas como fotografias reais de suas fazendas. A interface deve identificá-las como imagens ilustrativas.

Foram feitas três chamadas independentes, sem imagens de referência ou alvos de edição. A composição fotográfica horizontal foi inspirada apenas no tipo de imagem do wireframe fornecido. As três saídas foram inspecionadas visualmente: viveiros plausíveis, composição legível no card e ausência de texto, marcas ou pessoas identificáveis.

Os PNGs originais permanecem na pasta de imagens geradas do Codex. Os arquivos finais foram apenas convertidos para JPEG com qualidade 88, usando `System.Drawing` do Windows, sem recorte, redimensionamento ou edição semântica. Nenhuma dependência foi instalada.
